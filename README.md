**Populate_Maestro_specs:** A Python utility that automatically identifies MOSFET devices in Cadence Virtuoso and configures operating-point outputs across DC simulation tests in ADE Maestro. It supports customizable expressions (e.g., operating region, gm/Id and saturation margin), automatic plotting, and tolerance or range specifications. All settings can be enabled, disabled, or modified through a simple "specs.txt" configuration file, eliminating repetitive manual setup.

**Gen_TIA_TB:** Builds a complete characterisation testbench for a differential or single-ended transimpedance amplifier from one config file (tia_specs.txt): an open-loop and a closed-loop schematic plus a Maestro view with tests for DC/AC open-loop gain, closed-loop transimpedance/bandwidth/input impedance, input-referred noise, loop stability (differential, common-mode and CMFB stb) and transient THD/HD3. It also adds specs, global variables and corners. Every transistor in the TIA hierarchy gets region / saturation-margin / gm/Id outputs with user-defined specs (globally or per device). Pin mapping, design variables, analysis settings, specs and corners all live in tia_specs.txt and nothing technology-specific is built in.
      python3 tia_tb_gen.py tia_specs.txt --inspect   # list pins, transistors, variables
      python3 tia_tb_gen.py tia_specs.txt             # create schematics + maestro
Run it from your Virtuoso start-up directory (Python ≥ 3.6, virtuoso on PATH). 
**For differential TIAs, place an iprobe inside the CMFB loop (name set by cmfb_probe). The script tells you when this is still missing.
